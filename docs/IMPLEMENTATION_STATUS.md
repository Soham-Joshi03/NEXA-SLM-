# Implementation Status

## Uploaded files added

### `inference.py`
The supplied inference script provides:
- Single-token Mamba state updates with convolution and SSM caches.
- Single-token SW-GQA processing with a pruned sliding KV cache.
- Hybrid layer traversal for Mamba/MoE and SW-GQA/shared-MLP paths.
- Temperature and top-k sampling.
- Autoregressive generation with scratchpad and prompt prefill.

The uploaded Python source was committed without changing its model logic.

### Tokenizer configuration
The supplied `jamba_bbpe_tokenizer.json` is preserved as two consecutive text fragments under `tokenizer/` because the repository upload route has a per-read size limit. The source was validated before upload as JSON with:
- 32,768 vocabulary entries.
- 32,501 BPE merge rules.
- 11 added special tokens.

Reconstruct the exact root-level tokenizer file using:

```bash
python scripts/assemble_tokenizer.py
```

The script writes `jamba_bbpe_tokenizer.json` and validates that the reconstructed file is valid JSON.

## Required model module

The inference script imports:

```python
from train import Config, PerfectSLM, Mamba3Layer, SWGQA, apply_rotary_emb
```

Therefore, `train.py` must be present at the repository root before `inference.py` can run. That file was not included in this upload batch.

The inference script also requires PyTorch and Hugging Face Transformers. Exact version pins should be established when the training implementation is committed.
